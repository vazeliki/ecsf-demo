ECSF 2.0

This is a demonstration of how ECSF 2.0 will look like.

The 12 ECSF profiles have been revised and updated. This demo presents the revised tasks and their associated skill areas. By clicking on each skill area, users can see how the corresponding skill is expected to evolve across different proficiency levels.

For each skill area mapped to an ECSF profile, a target proficiency level is also assigned. This represents the level expected of a fully proficient practitioner of that profile. For example, the CISO profile is assigned Governance & Strategy at Level 4. This does not imply that every CISO must start at Level 4; a more junior CISO may naturally begin at Level 1 or 2 and progressively develop towards the target Level 4.

    Key Features

    How ECSF 2.0 is built: proficiency levels, target levels, and how tasks and skill areas are mapped to profiles.

    1. 01

      Proficiency levels

      In every skill area, levels progress by scope, autonomy and influence, not by different types of activity. Each skill area is described at four proficiency levels:

      L1

      Executes defined, narrow-scope tasks under supervision or against an established procedure, contributing to work rather than owning outcomes.

      L2

      Works independently on a single, well-defined piece of work from start to finish.

      L3

      Owns a domain or process end to end, across multiple cases, setting the approach and handling complexity and ambiguity without direction.

      L4

      Sets the direction, strategy, methodology or standards that others work within. It can be reached through a management path (senior managers, heads of function) or an expert path (recognised technical authorities).

    2. 02

      How levels progress

      Level descriptions are proficiency statements, not lists of profile tasks. Where they give examples, the examples illustrate the level and are not exhaustive.

    3. 03

      Profile levels are target levels

      The level shown for a profile in a skill area is the target level for a fully proficient practitioner of that profile. It isn't an entry requirement, and it isn't a maximum. A low level in a skill area outside the profile's core (for example L1) means the profile needs foundational proficiency in that area; it doesn't mean the practitioner is junior.

    4. 04

      How tasks are written

      • Generic wording: tasks are written so they apply to any type of entity. They avoid references to specific organisational settings and to named legislation, which would date quickly.
      • Granularity: each task describes a coherent responsibility at the level of a fully proficient practitioner. Overlapping tasks are merged rather than split, to keep the number of tasks manageable.
    5. 05

      How a profile's skill areas and levels are derived

      A profile includes a skill area only if at least one of its tasks is mapped to that skill area.

      • Each task is mapped to exactly one skill area, the one that reflects its primary purpose and output. Many tasks draw on several skill areas, but supporting skill areas are not mapped. Where a task combines more than one element, it is mapped according to its main purpose.
      • The profile's level is the level whose description the task wording supports. Where several tasks map to the same skill area, the highest level supported by any of them applies.
    6. 06

      Transversal skill areas

      S22 AI Literacy & Secure AI Use is a transversal skill area. Its profile levels are set directly, based on how each profile uses AI in its work.

    7. 07

      Skill area mapping to tasks

      A skill area is only mapped to a task where this skill is a real working requirement of the profile, and the level reflects the depth of the skill area the work needs. For example, Legal, Regulatory & Compliance (S03) is only mapped to tasks where having legal skills is a real working requirement. General legal awareness, expected of almost all profiles, is not mapped.

    8. 08

      No meaning in counts

      The number of tasks per profile doesn't indicate the profile's size or importance.
